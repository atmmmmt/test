# رفقة العمرة — Umrah Connect

## القرار الفني (31 October 2026)

الخيار العملي الأسرع للتجربة: **Murmur**، تطبيق صوت Bluetooth Mesh متوفر على iOS وAndroid، بلا بيانات/واي فاي/Hotspot أثناء الاتصال. الحد الرسمي للمجموعة **16 شخصاً**. لا يوجد دليل على نجاح **100 مستمع** بالتزامن، لذلك لا نعتمد عليه للعمرة قبل تجربة فعلية.

### كيف تستخدم النسخة الجديدة؟
- `/` واجهة **PWA تنظيمية** وليست محرك البث: توزيع المئة على سبع مجموعات، أسماء مجموعات Murmur، اسم/رقم المشترك، Checklist تجهيز الجهاز، تبويب المنظمين، سجل اختبار يدوي محلي، وروابط المتاجر.
- `/lab` مختبر WebRTC السابق للربط اليدوي بين الأجهزة على شبكة Wi-Fi محلية. **لا يعمل بدون شبكة IP مشتركة**.
- لا يوجد تكامل SDK أو تحكم عن بعد في Murmur، ولا تشارك حالة الاتصال أو أسماء المستمعين بين تطبيق Murmur وPWA.
- حالة الجاهزية المحفوظة في localStorage على جهاز واحد فقط؛ لا توجد قاعدة بيانات مشتركة.

### الاختبار الميداني الإجباري
1. آيفون + أندرويد دون Wi-Fi/بيانات، بلوتوث فقط.
2. اختبار ثلاثة/أربعة أجهزة مع إعادة تمرير الصوت.
3. مجموعة 14–16 شخصاً لمدة 20 دقيقة.
4. مجموعتان متجاورتان 28–30 جهازاً.
5. السبع مجموعات/100 شخص دفعة واحدة، في ظروف مماثلة للعمرة.
6. اختبر قفل الشاشة والسماعات وانقطاع أجهزة وسيطة وتعطيل المقاطع الفكاهية بالتطبيق المجاني.

إذا لم تنجح تجربة 100 جهاز لا تعتبر الحل مضموناً للرحلة.

### التشغيل
```bash
npm install
npm run typecheck
npm run build
npm run dev
```
انشر على HTTPS، وافتح PWA وثبّته **قبل انقطاع الإنترنت**. جرّب وضع الطيران وتشغيل Bluetooth والتحقق من عمل الموقع المخزن وتطبيق Murmur فعلياً.

**مهم:** PWA لا يوفر Bluetooth Mesh audio بين آيفون وأندرويد. الصوت عبر تطبيق Murmur الخارجي فقط. المشروع لا يتضمن أي تسجيلات صوتية محفوظة.
